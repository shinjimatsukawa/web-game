# 🌟 もじあそび ランド 🌟
4歳児が楽しく学べる ひらがな・カタカナ ウェブゲーム

iPadのSafariで直感的に遊べる、4歳前後のお子様向け知育Webゲームです。  
外部ライブラリ不要のPure HTML/CSS/JavaScriptで構成されており、**GitHub Pagesでそのまま完全無料で公開**できます。

---

## 🎮 主な機能・あそびかた

### 1. 🎯 もじ あてっこ（かるたクイズ）
- 「『あ』はどれかな？」と音声とイラストのヒントで出題。
- 4枚の大きなカードからタッチして解答。
- **4歳児に優しい設計**: 間違えても不快な「ブブー」音は鳴らず、優しく揺れて「おしい！もういっかい！」と励まします。
- 5問正解でキラキラファンファーレとともに「ごほうびシール」をゲット！

### 2. 📖 あいうえお ひょう（おしゃべり図鑑）
- あ行〜わ行の50音表。
- 文字カードをタッチすると大きくポップアップし、「あ！ アイスクリーム！」と音声読み上げ。
- 「ひらがな」と「カタカナ」をいつでもワンタップで切り替え可能。

### 3. 🧩 ことば パズル（文字ならべ）
- 「くるま 🚗」「ねこ 🐱」などの絵を見て、バラバラになった文字カードを順番にタッチして言葉を完成させます。
- 3問クリアで「ごほうびシール」をプレゼント！

### 4. ✨ ごほうび シールちょう
- ゲームをクリアするたびに、可愛い動物や乗り物のシール（全16種）が集まります。
- iPadのSafari（LocalStorage）に自動保存され、次回遊ぶときも続きから楽しめます。
- 集めたシールをタップすると、ピョンと跳ねて名前を読み上げます。

## 🚀 GitHub Pages での公開手順（かんたん3ステップ）

1. **GitHubにコードをプッシュ**
   ```bash
   git add .
   git commit -m "Initial commit: もじあそび ランド"
   git push origin main
   ```

2. **GitHub Pages を有効化**
   - GitHubの該当リポジトリのページを開きます。
   - **「Settings」**（設定）タブをクリック。
   - 左メニューの **「Pages」** を選択。
   - **「Build and deployment」** の **「Source」** を `Deploy from a branch` に設定。
   - **「Branch」** を `main`（または `master`）、フォルダを `/ (root)` にして **「Save」** をクリック。

3. **公開URLにアクセス**
   - 数分待つと、上部に `Your site is live at https://<ユーザー名>.github.io/<リポジトリ名>/` と表示されます。
   - そのURLをiPadのSafariで開けば、すぐに遊べます！

## 📱 iPad Safariでさらに楽しく遊ぶ裏技（全画面アプリ化）

iPadのSafariで公開URLを開いた状態で、以下の設定をすると**アドレスバーが消えて本物のアプリのように全画面で**遊べます！

1. 画面右上の **共有ボタン**（四角から矢印が出ているアイコン）をタップ。
2. メニューから **「ホーム画面に追加」** をタップ。
3. 右上の **「追加」** をタップ。
4. iPadのホーム画面に「もじあそび」のアイコンが作成され、タップするだけでいつでも全画面で快適に遊べます。

## 🛠️ 技術仕様
- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+)
- **サウンドエンジン**: 
  - **効果音**: Web Audio API（ブラウザ内蔵オシレーター合成による低遅延・高音質サウンド）
  - **音声読み上げ**: Web Speech API (`SpeechSynthesis`, 日本語 `ja-JP` エンジン)
- **演出**: Canvas Confetti（軽量自作紙吹雪パーティクル）
- **データ保存**: Web Storage API (`localStorage`)
